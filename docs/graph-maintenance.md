# Graph Maintenance

The graph should communicate architectural relationships, not merely produce a dense visualization.

When documentation changes:

1. Link the note from its directory `index.md`.
2. If the note is a major entry point or legacy/supplemental document, link it from [[Documentation Graph]].
3. Add wiki links from the note to related domains, flows, architecture, API contracts, or decisions.
4. Update inbound links when a note is renamed or removed.
5. Avoid linking unrelated notes solely to eliminate orphan nodes.

The source code remains authoritative. Begin repository navigation at [[index|Project Knowledge Base]].
